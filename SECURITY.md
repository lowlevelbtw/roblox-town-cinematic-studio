# Security policy

## Reporting a vulnerability

Please do not publish credentials, private recordings, personal information, or an unpatched exploit in a public issue.

Use GitHub's **Report a vulnerability** option in the repository's Security tab to submit a private vulnerability report when that feature is available. If private reporting is not enabled, contact the maintainer through the GitHub profile at https://github.com/lowlevelbtw and request a private reporting channel.

Include the affected file or component, impact, reproduction conditions, and a suggested mitigation if known. Allow reasonable time for investigation and a fix before public disclosure.

## Scope

This policy covers the code, scripts, templates, and documentation maintained in this repository. Third-party services and Roblox experiences have their own security reporting processes.
