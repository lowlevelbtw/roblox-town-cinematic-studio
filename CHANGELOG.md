# Changelog

All notable changes to `roblox-town-cinematic-studio` / `roblox-town-director` are documented in this file.

## [0.2.0-consolidated-r2] - 2026-11-23
*Built on frozen `v0.1.1` RC6 baseline on feature branch `feature/one-prompt-autopilot-v0.2.0`.*

### One Prompt → One Finished Video (`v0.2.0`)
- Added **One-Prompt Autopilot** section (`1A`) to `SKILL.md` defining Autonomous (default), Interactive, and User-Supplied Script modes, mandatory 4-category Output Classification (`Real Roblox production`, `Code-driven Roblox-style animation`, `AI-generated video`, `Animatic`), and the Hard Final Delivery Gate (`COMPLETE` vs. `INCOMPLETE`/`FAILED`).
- Added **16 Executable Caption Styles** (`skills/roblox-town-director/scripts/caption_styles.py` + `templates/caption-styles.json`): `C01`–`C15` genuinely distinct ASS/FFmpeg presets (including karaoke `\kf`, pop `\t`, keyword highlighting, speaker badges, color-coded dialogue, gaming HUD, documentary, and dynamic 9:16 + 16:9 scaling) plus `C16` Auto Adaptive selector, wired into `mux_audio_and_subtitles_to_video` and CLI (`--caption-style`, `list-caption-styles`).
- Added **Per-Scene Persistent State, Recovery & Final Delivery Gate** (`skills/roblox-town-director/scripts/production_state.py`): atomic JSON checkpoints (`os.replace`) resuming failed scenes without restarting completed scenes, user-script preservation lock, honest host memory inspection, and FFprobe + full FFmpeg decode delivery gate.
- Added **Multi-Scene Cinematic Assembler** (`scripts/video_assembler.py`: mixed video/capture/still normalization, FFmpeg `xfade` transitions, dialogue-aware `sidechaincompress` BGM ducking, per-scene recovery checkpoints), **Visual QC** (`scripts/visual_qc.py`: FFmpeg `blackdetect` blank-segment checks + PIL scene contact sheets), and **Unified Autopilot Runner** (`scripts/autopilot.py`).
- Fixed `F-12` (`ProductionStateManager.get_pending_or_failed_scenes()` now validates cached scene assets via FFprobe rather than trusting file existence) and `F-13` (`evaluate_final_delivery_gate()` rejects unverified `captions_burned_in=True` booleans and requires FFprobe subtitle streams or SHA-256 verified `caption_render_receipt` hashes).
- Closed `F-14` (direct voice-stage execution in `scripts/autopilot.py` supporting pre-generated audio, BYO `voice_manifest_path` via `voice_backend.py`, and `voice_profiles_path` + `script_text` via `VoiceGenerationPipeline` with cached-voice recovery and honest unavailable-provider reporting) and `F-15` (dialogue duration vs. video duration truncation guard in `mux_audio_and_subtitles_to_video` with explicit `allow_audio_tail_sec`/`allow_audio_truncation` controls).
- Engineering audit fixes (`F-16`–`F-20`): trimmed ducked BGM mix to `max(dialogue_duration, target_duration_sec)` in `video_assembler.py`/`autopilot.py` so long BGM tracks never trigger false `F-15` dialogue truncation; moved temporary `.ass` & `_cap.mp4` cleanup into `try/finally` in `pipeline.py`; added `pillow` install and `feature/**` push trigger to `.github/workflows/ci.yml`; escaped single quotes in FFmpeg concat lists; validated target video dimensions/FPS and finite ducking volumes.
- Independent RC2 audit fixes (`F-21`–`F-23`): validated `max_audio_overrun_sec` and `allow_audio_tail_sec` as finite and `>= 0.0` in `mux_audio_and_subtitles_to_video()` so `NaN`/`inf`/negative values cannot bypass `F-15` dialogue truncation protection (`F-21`); extended `try/finally` cleanup across the full styled-caption render and muxing workflow so `.ass` and `_cap.mp4` temp files are always removed on render failure, mux error, or timeout (`F-22`); added `verify_output_classification()` in `production_state.py` and wired it into `evaluate_final_delivery_gate()` and `autopilot.py` so unverified or still-image-only claims downgrade conservatively to `animatic` (`F-23`).
- Independent RC3/RC4 audit fixes (`F-24`–`F-25`): validated summed `allowed_overrun = max_audio_overrun_sec + allow_audio_tail_sec` with `math.isfinite()` (and rejected boolean tolerances) in `pipeline.py` so `1e308 + 1e308` cannot overflow to `inf` and bypass `F-15` dialogue truncation protection (`F-24`); removed public attestation spoofing from `production_state.py`/`autopilot.py` so the local FFmpeg pipeline (`ffmpeg_multi_scene_assembler`) never marks external Roblox, Blender/code-renderer, or AI video claims as `provenance_verified=True`—preserving caller metadata strictly as `declared_provenance` and downgrading conservatively to `animatic` (`provenance_status="unverifiable_external_origin"`) until genuine integrated producer adapters exist (`F-25`). Also scaled synthetic FFmpeg fixtures in `tests/test_v020_production.py` (`180x320@12fps`) to eliminate combined-discovery timeout risk on CPU-constrained containers without weakening any assertion.
- Pre-MT-05 targeted defect closure (`D-MT04-01`, `D-MT04-02`, `D-MT03-01`, `D-MT03-03`, `O-S12L-02`, adapter-boundary cloning guard): implemented `VoiceProfileManager.migrate_provider()` with pre-flight validation, automatic atomic rollback, and preservation of internal voice IDs and approved dialogue assignments (`D-MT04-01`); upgraded `ElevenLabsAdapter` to accept `connector_authenticated` transport or in-memory `credential_provider` without requiring env-var API keys or leaking secrets (`D-MT04-02`); aligned exact `0:15.5` door-open/creak timestamps and removed unsupported verification claims in `examples/solo-short-example.md` marking untested game behaviour `UNVERIFIED` (`D-MT03-01`, `D-MT03-03`); updated `run_project_audio_qc()` with `blocked_dialogue_lines`, `production_mechanism_failures`, and `qc_outcome_category` (`O-S12L-02`); added `ProhibitedVoiceCloningError` defense-in-depth policy and unconditionally disabled `ElevenLabsAdapter.create_authorized_clone()` in `v0.2.0` across all transports, connector-auth modes, and labels while preserving connector/callback TTS (`D-RC6-01`).
- MT-05 caption engine fix (`D-MT05-02`): replaced character-count-only tail-joining in `scripts/caption_styles.py` with rendered pixel-width wrapping (`measure_text_width_px` via fontconfig/PIL with Unicode-aware fallback), safe horizontal margins (`>= 6%` left/right for both `9:16` 1080×1920 and `16:9` 1920×1080), long-word/Unicode splitting, speaker-badge prefix width accounting, `WrapStyle: 0`, and timed sub-cue pagination for unusually long sentences across all 16 styles (`C01`–`C16`).
- RC8/RC9 audit fixes (`D-RC8-01`, `D-RC9-01`): replaced float-rounded pagination in `scripts/caption_styles.py` with exact integer-centisecond allocation enforcing `MIN_PAGE_DURATION_SEC = 0.25s` across **both single-page and multi-page events** (adding sync-preserving same-speaker adjacent short-cue coalescing and raising `CaptionRenderError` for standalone `< 0.25s` cues without extending the timeline or discarding dialogue), plus persistent rendered portrait/landscape PNG samples and manifest under `evaluations/caption-samples-rc10/`, compact `\fs` safe fallback when cues are tight, clear `CaptionRenderError` when a cue cannot fit readably without zero-duration flashes or invented timeline duration, and grapheme-cluster-safe `_split_long_token()` preserving Unicode combining marks and ZWJ/skin-tone emojis.
- Consolidated remediation pass (`CR-01`–`CR-04`, r2): fixed near-EOF/out-of-range frame extraction crash in `visual_qc.generate_scene_contact_sheet()` (`CR-01`); upgraded `autopilot.py` (`production_report.json`) and `voice_intelligence/pipeline.py` (`audio_qc_report.json`) final JSON report writes to atomic `tempfile.mkstemp` + `os.replace` with failure-path rollback/temp-cleanup regression tests (`CR-02`); completed 100% AST-verified `stdin=subprocess.DEVNULL` on every `subprocess.run()` call and `-nostdin` on every FFmpeg command list across all production scripts (`caption_styles.py`, `voice_backend.py`, `voice_intelligence/pipeline.py`, etc.) and all test modules (`CR-03`); reconciled `references/voice-provider-adapter.md` and upgraded `.github/workflows/ci.yml` with local Markdown link and sample-manifest SHA-256 verification (`CR-04`).
- Expanded `tests/test_v020_production.py` to `34/34` passing tests alongside all 48 preserved RC6 tests (**82 / 82 total passing**). Live ElevenLabs TTS execution via secure connector, Muse E2E (MT-06–MT-10), and remote GitHub Actions remain external gates.

- Added CLI entrypoint (`skills/roblox-town-director/scripts/voice_intelligence/__main__.py`), FFmpeg video/audio/subtitle muxing (`mux_audio_and_subtitles_to_video` with `preserve_source_audio: bool = False`), explicit `independent_identity_verified: false` consent-boundary enforcement in `voice_cloning.py`, and formal acceptance criteria (`skills/roblox-town-director/evaluations/voice-intelligence-acceptance.md`).

- Added HTTPS URL-scheme validation (`_validate_http_url`), structured malformed-JSON handling (`_parse_json_response`), upstream error-body key redaction, atomic JSON state writes (`os.replace`), FFmpeg/FFprobe missing-binary and timeout guards, and mux volume validation.

- Disabled remote provider voice-cloning submission completely in `voice_cloning.py` (`v0.1.1`): `allow_unverified_staging=True` performs strictly local FFprobe validation and persists `provider_voice_id=None`, `consent_status="self_attested_unverified"`, `availability_status="unavailable"`, and `remote_submission_performed=False` with zero provider HTTP calls; added cloner duplicate-ID and persistence-failure regression tests (`test_40`).
- Expanded automated test suite to **48 passing tests** (`8/8` locally executed FFmpeg/wave tests in `tests/test_voice_backend.py` + `40/40` unit, CLI, FFmpeg muxing, route/sanitization/hygiene regression, and mocked-HTTP tests in `tests/test_voice_intelligence.py`).
