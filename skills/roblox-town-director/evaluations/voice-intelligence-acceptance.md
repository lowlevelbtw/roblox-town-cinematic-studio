# Voice Intelligence & Cloning Acceptance Criteria

This document defines explicit **pass/fail acceptance criteria** and **required evidence** for independent review (Gemini 4 Hydrogen) of the `voice_intelligence` module on branch `voice-backend-integration-0.1.1`.

> **Test Scope Rule:** Mocked HTTP transport tests verify local orchestration, state persistence, error handling, and FFmpeg/FFprobe media pipelines. They do **not** verify live external provider APIs. Live API acceptance requires an online environment with `ELEVENLABS_API_KEY` and explicit user spending approval.

| # | Area | Pass Criteria | Fail Criteria | Required Evidence | Current Test Mode |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **1** | **Profile Persistence** | `VoiceProfileManager` creates, validates, reloads, updates, disables, and removes `V01`–`V06` and custom profiles in JSON with zero secret fields. | Duplicate IDs overwrite silently, invalid fields pass, or profiles fail to reload across instances. | Unit test stdout (`test_01`, `test_02`) + inspected JSON store. | Unit-tested |
| **2** | **Character Voice Locking** | `CharacterVoiceAssigner` parses scripts, locks `character_id -> voice_id` across scenes, and blocks unavailable voices instead of silently substituting. | Silent voice swap when locked voice is disabled/missing, or inconsistent voice across scenes. | Unit test stdout (`test_03`, `test_14`). | Unit-tested |
| **3** | **Consent Boundaries** | `AuthorizedVoiceCloner` requires explicit adult authorization, rejects minors and impersonation, and always records `independent_identity_verified: false` (`user_self_attestation`). | Unconsented or minor sample accepted, or self-attestation represented as `independent_identity_verified: true`. | Unit test stdout (`test_09`, `test_17`, `test_37`, `test_40`: remote cloning disabled; local staging makes 0 provider calls and stores `provider_voice_id=None`, `self_attested_unverified`, `unavailable`). | Unit-tested + Mocked HTTP |
| **4** | **Provider Authentication** | `ElevenLabsAdapter` reads `ELEVENLABS_API_KEY` from env only; missing key or HTTP 401/403 raises `ProviderAuthError`; CLI exits non-zero without printing secrets. | Hardcoded keys, keys written to disk/logs/stdout, or silent pass on 401/missing key. | Unit/CLI test stdout (`test_05`, `test_18`). Live `/v1/user` call required for live sign-off. | Mock-tested (Live `BLOCKED`) |
| **5** | **TTS Generation & Voice Design** | `VoiceDesigner` maps only provider-supported controls; `ElevenLabsAdapter.synthesize_speech` writes non-empty audio; FFprobe validates streams. | Unsupported controls crash or fabricate support; 0-byte or corrupt audio marked approved. | Mocked HTTP + real FFprobe stdout (`test_08`, `test_10`, `test_11`, `test_23` current `/v1/text-to-voice/design` & `/v1/text-to-voice`, `test_27` control filtering). Live audio + human listening required for live sign-off. | Mock-tested + Real FFprobe (Live `BLOCKED`) |
| **6** | **Voice Cloning** | Samples validated via FFprobe/FFmpeg before upload; provider `voice_id` persisted; optional verification clip tested; revoke/delete supported. | Corrupt/silent/short samples uploaded, or private recordings committed to repo. | Local FFprobe + `test_40` (0 provider calls during staging; duplicate-ID & save-failure covered) + `test_39` (`files[]` adapter format check). Remote voice cloning disabled in `v0.1.1` pending independent identity/age verification. | Mock-tested + Real FFprobe (Live `BLOCKED`) |
| **7** | **Dialogue Mixing** | `SharedVoiceManager` additively mixes simultaneous speakers with `-1.0 dBFS` headroom; no overwriting or int16 overflow. | Overlapping clips overwrite each other or clip above `0 dBFS`. | Real FFmpeg/wave test (`test_voice_backend.py` `test_03`, `test_15`). | Real FFmpeg/Python |
| **8** | **Subtitle Synchronization** | `subtitles.srt` timestamps match approved stem `start_sec`/`end_sec` with no silent truncation; out-of-range timings fail validation. | Desynced SRT cues or silent timeline truncation. | Real SRT output + `test_voice_backend.py` `test_04`. | Real FFmpeg/Python |
| **9** | **Video Muxing** | `mux_audio_and_subtitles_to_video` combines dialogue (+ optional BGM/SFX + SRT sidecar/embedded `mov_text`), preserves source resolution & FPS via `-c:v copy`, and rejects invalid media. | Resolution/FPS altered, missing audio ignored, or FFmpeg mux claimed as Roblox Studio rendering. | Playable MP4 fixture + FFprobe stream report (`test_19`, `test_20`, `test_21` `preserve_source_audio`, `test_22` CLI `mux-video`/`run-pipeline`). | Real FFmpeg/FFprobe |
| **10** | **Recovery & Error Handling** | Transient 5xx/429 errors retry up to `max_retries`; crash recovery skips already-approved lines and regenerates only failed lines. | Approved lines unnecessarily re-billed/regenerated, or non-retryable 401/404 looped. | Pipeline state JSON + call count assertions (`test_13`, `test_16`). | Mock-tested + Real FFmpeg |
| **11** | **Security & Credentials** | `.gitignore` excludes `.env*`, `*.key`, private voices, and caches; zero API keys appear in code, tests, manifests, CLI output, or error messages. | Any credential string or env var value leaked in logs, exceptions, or tracked files. | `git status`, `git diff`, CLI secret-redaction (`test_18`, `test_22`), path-traversal & symlink sanitization (`test_06`, `test_07`, `test_24`, `test_26`, `test_34`), URL-scheme & error-key redaction (`test_29`, `test_32`), multipart header escaping (`test_28`), clean `examples/` (`test_25`), and `.github/workflows/ci.yml`. | Verified locally |
